PDF 서명 (웹)
============

브라우저에서 PDF에 서명 이미지를 붙이고, 링크로 여러 명이 같은 문서에 서명하는 프로그램.
필요한 것: Python 3.8+ (추가 패키지 없음). 라이브러리(pdf.js, pdf-lib)는 static/vendor 에 포함되어 있어 인터넷 없이도 동작.

실행
  python3 server.py              # 기본 포트 8000, 모든 네트워크 인터페이스
  python3 server.py --port 9000 --data /경로/저장폴더

  접속: http://localhost:8000/   (같은 네트워크의 다른 사람은 서버가 출력하는 http://<IP>:8000/)

사용법
  1. "PDF 열기" (또는 드래그 앤 드롭) → 서버에 올라가고 공유 링크(/d/<ID>)가 생김
  2. 링크를 서명할 사람들에게 전달
  3. 각자: 이름 입력 → "서명 이미지 불러오기"(PNG/JPG 등) → 문서 위 원하는 곳 클릭
     - 드래그로 이동, 오른쪽 아래 모서리 또는 왼쪽 슬라이더로 크기 조절
       ("비율 유지" 해제 또는 Shift+드래그로 가로/세로 따로 조절)
     - "흰 배경 투명하게": 종이에 쓴 서명 사진의 흰 배경을 지우고 여백을 자름
     - 또는 "서명 그리기": 마우스·펜·손가락으로 직접 서명 (펜은 필압 반영, Ctrl+Z 되돌리기)
       그린 서명도 "내 서명"에 저장되어 다음에 다시 쓸 수 있음
  4. "서명 적용·저장" → 서명이 PDF 페이지에 합쳐져 새 버전으로 저장
     항상 최신 버전 위에 덧붙이므로 동시에 저장해도 다른 사람 서명이 지워지지 않음.
     다른 사람이 저장하면 열려 있는 화면도 5초 안에 자동 갱신.
  5. "PDF 다운로드" → 서명이 들어간 PDF 저장 (왼쪽 "기록"의 "받기"로 이전 버전도 받을 수 있음)
  - 확대/축소: 위쪽 －/＋/맞춤 버튼, 또는 Ctrl+마우스 휠 (노트북 터치패드는 두 손가락 벌리기)
  - 문서 교체 (서버 컴퓨터에서만): 공유 링크는 그대로 두고 PDF만 다른 파일로 바꿈.
    이미 받은 서명은 새 파일로 옮겨지지 않음 (이전 버전은 기록에 남음)
  - 문서 목록 (서버 컴퓨터에서만): http://localhost:8000/ 또는 위쪽 "문서 목록" 버튼
    올린 모든 문서의 서명 수·서명한 사람·마지막 변경 시각, 링크 복사, 최신 PDF 받기 (5초마다 갱신)
  서버에 연결이 안 되면 로컬 모드로 동작 (내 브라우저 안에서만 서명 → 다운로드).

외부 공개 시 동작
  - 새 문서 올리기는 서버 컴퓨터(http://localhost:8000/)에서만 가능. 다른 사람은 공유 링크로 서명만 함
    (모두 허용하려면 --allow-remote-upload)
  - localhost 로 열어도 공유 링크는 외부 주소(기본: http://<이 컴퓨터 IP>:<포트>)로 만들어짐
    터널 등 다른 주소를 쓰면: python3 server.py --public-url https://xxxx.trycloudflare.com
  - 모든 서명이 끝나면 같은 링크를 열어 "PDF 다운로드" → 최신(전부 서명된) 버전

학교 등 방화벽 안의 PC를 외부에 공개하려면 (권장)
  공인 IP:8000 으로 직접 접속은 학교 방화벽 때문에 외부(모바일 데이터 등)에서 불안정함.
  Cloudflare 무료 터널을 쓰면 방화벽과 무관하게 https 주소로 접속 가능.
  1회 설치:  curl -L -o ~/.local/bin/cloudflared https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64 && chmod +x ~/.local/bin/cloudflared
  실행:      ./start-public.sh          (터널 + 서버를 함께 켜고, 공유 링크를 터널 주소로 만듦)
  문서 올리기는 여전히 이 PC의 http://localhost:8000/ 에서.
  터널 주소는 실행할 때마다 바뀌므로 재시작하면 링크를 다시 보내야 함.

인터넷 너머로 공유하려면
  - 공인 서버/VPS에서 실행하거나,
  - 터널 사용 예: cloudflared tunnel --url http://localhost:8000   (출력된 https 주소를 공유)
  인증 기능은 없으므로 링크(추측하기 어려운 무작위 ID)를 아는 사람은 누구나 접근 가능.

저장 구조
  data/<ID>/v1.pdf, v2.pdf ...  (버전별 원본 보존), data/<ID>/meta.json (기록)
  특정 버전 받기: /api/docs/<ID>/pdf?v=1
